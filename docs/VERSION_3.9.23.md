# Versión 3.9.23

## Menú y administración

- El menú superior de Personal conserva las acciones operativas y el acceso a Ajustes.
- El menú superior de Llaves conserva las acciones operativas y el acceso a Ajustes.
- Apariencia, pantalla inicial, usuario, vibración, recordatorios, versión e información técnica
  quedan agrupados dentro de Ajustes.
- Administración se muestra dentro de Ajustes únicamente para el rol Administrativo.
- Los usuarios normales no ven el acceso a Administración.
