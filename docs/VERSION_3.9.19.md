# Versión 3.9.19

## Calidad de vida

- Se muestra una franja visible cuando el dispositivo no tiene una conexión validada a Internet.
- Se bloquean las operaciones que escriben datos mientras no hay conexión: ingresos, salidas, retiros,
  devoluciones y acciones administrativas sobre los registros.
- La información ya cargada permanece visible para consulta mientras se recupera la conexión.
- Al recuperar Internet, los controles se habilitan automáticamente.
