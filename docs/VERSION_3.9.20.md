# Versión 3.9.20

## Mejoras de calidad de vida

- Al volver a la app se actualiza el rol del dispositivo. Si el permiso fue retirado, se bloquea o se
  cierra la pantalla administrativa sin exigir reiniciar la aplicación.
- La persona o llave modificada queda resaltada durante unos instantes después de guardar el movimiento.
- Se emite una vibración breve únicamente cuando un ingreso, salida, retiro o devolución se guarda
  correctamente.
- La interfaz respeta el modo oscuro configurado en el teléfono, con colores adaptados para paneles,
  filtros, campos y tarjetas.

## Se mantiene

- El bloqueo de operaciones de escritura cuando no hay conexión validada.
- Los filtros rápidos de personal y llaves.
- La firma estable del proyecto para permitir actualizar instalaciones anteriores.

No se incorpora una sección de movimientos recientes ni se muestra la hora del último movimiento en las
tarjetas.
