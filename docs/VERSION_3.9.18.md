# Versión 3.9.18

## Mejoras de calidad de vida

- Se agregaron filtros rápidos de personal: `Todos`, `Dentro` y `Fuera`.
- Se agregaron filtros rápidos de llaves: `Todas`, `Disponibles` y `Prestadas`.
- Los filtros se combinan con la búsqueda por nombre o identificación.
- El filtro activo queda destacado para saber qué lista se está mostrando.
- GitHub Actions ahora ejecuta las pruebas también cuando cambian los recursos y layouts Android.

## Verificación

- Se validaron los archivos XML de recursos y layouts.
- La ejecución local de Gradle quedó pendiente por un problema del entorno al establecer una conexión local.
- GitHub Actions ejecutará la compilación y las pruebas al subir esta versión.
